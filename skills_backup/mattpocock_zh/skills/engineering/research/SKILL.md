---
name: research
description: 根据高可信度的一手来源研究问题，并将结果保存为仓库中的 Markdown 文件。适用于用户需要研究某个主题、收集文档或 API 事实，或将资料阅读工作交给后台代理的情况。
---

启动一个**后台代理**进行研究，这样你可以在它阅读资料时继续工作。为它开启全新的上下文窗口。

它的任务是：

1. 根据**一手来源**（官方文档、源代码、规范、第一方 API）调查问题，而不是依赖对这些来源的二手解读。将每一项论断追溯到对其负责的原始来源。
2. 将研究结果写入一个 Markdown 文件，并为每项论断标注来源。
3. 保存到仓库现有的此类笔记目录，并遵循既有约定；如果没有约定，就选择合理的位置，并说明保存在哪里。
