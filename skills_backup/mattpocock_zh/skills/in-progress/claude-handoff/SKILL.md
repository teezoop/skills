---
name: claude-handoff
description: 将当前对话交给一个全新的后台代理，由其立即接续工作。
argument-hint: 下一次会话将用于什么？
disable-model-invocation: true
---

为当前对话编写交接摘要，使一个全新的代理能够继续工作。保存到用户操作系统的临时目录，再将其作为提示词启动后台代理：`claude --bg --name "<descriptive name>" -- "$(cat <summary file>)"`。通过文件传递，避免 shell 执行摘要中的反引号或展开 `$`。代理从当前工作目录启动，并立即返回；用户通过 `claude agents` 管理它。

始终使用 `-n` / `--name` 传入有描述性的名称，例如 `--name "Fix login bug"`。该名称会显示在任务列表、会话选择器和终端标题中。

摘要应包含“建议技能”一节，说明下一位代理应通过 Skill 工具加载哪些技能。

不要重复其他产物（规格、计划、ADR、工单、提交、差异）中已有的内容。改为通过路径或 URL 引用。

隐去所有敏感信息，例如 API 密钥、密码或个人身份信息，因为摘要将成为代理的提示词。

如果用户传入参数，将其视为下一次会话重点的描述，并据此调整摘要。
