---
name: handoff
description: 将当前对话压缩成交接文档，供另一位代理继续处理。
argument-hint: 下一次会话将用于什么？
disable-model-invocation: true
---

编写交接文档，总结当前对话，使一位全新的代理能够继续工作。保存到用户操作系统的临时目录（优先 `$TMPDIR`，否则 `/tmp`；Windows 使用 `%TEMP%`），而不是当前工作区。

文档中应包含“建议技能”一节，指出下一位代理应通过 Skill 工具调用哪些技能。

不要重复其他产物（规格、计划、ADR、工单、提交、差异）中已有的内容。改为通过路径或 URL 引用它们。

隐去所有敏感信息，例如 API 密钥、密码或个人身份信息。

如果用户传入了参数，将其视为对下一次会话重点的描述，并据此调整文档。
