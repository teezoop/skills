这是编写任何供代理消费的文档的参考：技能、`AGENTS.md` / `CLAUDE.md`，或通过指针访问的文档。包装形式不同，写法相同：相同的调节手段能让它们变得可预测，因为代理每次遵循的是相同*过程*，而不是产出相同结果。

所写文档是一项技能时，阅读 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.md)，了解前置元数据、调用方式选择和路由技能。

## 上下文指针

**上下文指针**是一条保留在代理上下文中的引用，它命名一份上下文之外的材料，并编码何时应读取它。技能描述就是一种；`AGENTS.md` 中指向某份文档的一行也是同一种事物。决定代理何时、以多高可靠性访问材料的是指针的*措辞*，而非目标本身。必读目标被藏在措辞薄弱的指针后面，会造成执行方差：先强化措辞，只有强化无效时才将材料内联。

指针承担两项工作：说明材料是什么，以及列出应触发读取的**分支**。分支是文档处理的一种独立情况，使不同运行沿不同路径推进。始终加载的指针每个字在每轮都产生成本，因此比正文更需要精简：

- **将引导词放在前面**：指针正是它发挥触发作用的位置。
- **每个分支一个触发点。** 给同一分支换名的同义词，只是把一个分支写了两遍；合并它们，只保留真正不同的分支。
- **删掉正文已经表达的身份说明。**

## 两种负担

每增加一份文档或一条指针，都在消耗以下两种预算之一：

- **上下文负担**是始终加载的内容占用代理窗口的成本，例如 `AGENTS.md` 中的一行、技能描述，或任何每轮都在上下文中的内容。无论是否触发，它们都消耗 token 和注意力。
- **认知负担**是人类承担的成本：有哪些文档、何时应使用哪一份。人类是索引。这不是要一味最小化的成本，而是人类自主权的代价：需要人类判断的地方值得投入，不需要的地方则应去掉。

仅经由指针访问的材料，用指针本身一行的成本避开上下文负担；完全没有指针的材料，则全部依赖人类的认知负担。

## 信息层级

文档由两类内容构成：**步骤**，即代理按顺序执行的动作；**参考**，即按需查阅的定义、规则和事实。两者可自由组合：全是步骤的操作配方、全是参考的审查规则或本技能，或者二者兼有。核心决策是每段内容应位于**信息层级**的哪一级；这把阶梯按代理需要材料的即时程度排序：

1. **文件内步骤**是首要层级，说明代理按顺序做什么。
2. **文件内参考**按需查阅。它常常是一组合理的平级条目，例如审查中的所有规则位于同一级，这样安排完全可以，并非异味。
3. **外置参考**放入独立文件，通过上下文指针访问，只有触发指针时才加载。可以是同文件夹中的兄弟文件，也可以是位于任何地方、可被任意文档指向的外部参考。

下放太少，顶层膨胀；下放太多，代理真正需要的内容又被隐藏。整个决策就在于权衡这股张力。

**渐进披露**是沿阶梯下移：将内容移出主文件、放到指针后面，使顶层仍然清晰。它首先不是 token 优化，而是保护层级结构的方式。分支是最清晰的披露判断标准：所有分支都需要的内容内联，只有部分分支用到的内容放在指针后面。如果文档包含步骤，本应外置的文件内参考会埋没步骤，让代理是否关注它们变成碰运气，因此这影响执行方差，而不只是可读性。

**就近放置**是文件内部的配套原则：阶梯决定某段内容放*多深*，就近放置决定到了那一级后*什么挨着什么*。把一个概念的定义、规则和注意事项放在同一标题下，不要分散，让读到一部分时也能读到相邻内容。检验方式是：文档是否像专门为代理写的文档。成组内容像，散落内容不像。（这与重复不同：重复是在两处表达同一意思；分散则是把一个意思拆散到多处。）

**蔓延**是这里的失败模式：即使每一行仍然有效且不重复，文档也可能只是太长。注意力被摊薄，每多一行就多一行需要维护相关性。解决办法仍是阶梯：将参考放到指针后面，按分支或顺序拆分，让每条路径只携带所需内容。

## 步骤与完成标准

每个步骤都以**完成标准**结束，即告诉代理何时工作完成的条件。它通过两种属性发挥作用：

- **清晰度**：代理能否区分完成与未完成？模糊边界，例如“达成理解”，容易导致**过早完成**，在实际完成前结束步骤，注意力滑向*完成这件事本身*。前方可见的后续步骤，即**完成后的步骤**，提供诱惑；标准的清晰度提供阻力。按顺序防范：**先明确边界**，因为局部且成本低；只有边界确实无法进一步明确，*并且*观察到代理抢跑时，才拆开顺序、隐藏后续步骤。隐藏只在真正跨越上下文边界时有效，例如交接或派发子代理；内联调用仍把后续步骤留在上下文中，没有清除任何内容。
- **要求强度**：标准究竟要求多少工作。“每个修改过的模型都有交代”会迫使代理全面处理，而“生成变更清单”不会。要求强度驱动**调查投入**，即代理在任务内部进行的挖掘，它隐含在措辞中，而不单独写成步骤。它也不限于步骤：“应用每条规则”约束整组平级参考，正如“完成每个步骤”约束顺序流程，因此纯参考文档也能要求全面性。

最强的标准既可检查，又要求穷尽。

## 何时拆分

把一份文档拆成两份，会增加两种负担之一，因此只有收益值得时才拆：

- **按顺序拆分**：后续步骤诱使代理匆忙跳过当前步骤时，拆开步骤序列。让后续步骤不可见，可以促使代理在当前任务上投入更多调查。也要警惕反面：合并序列会让当前步骤暴露于后续内容，诱发过早完成。
- **按调用方式拆分**：这是技能特有的情况，见 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.md)。

## 引导词

**引导词**是模型预训练中已有的简洁概念，代理执行文档时用它思考，例如*课程*、*战争迷雾*、*曳光弹*。重复的是一个词，而非整句话，它会积累分布式定义，借助模型已有先验，用最少 token 锚定一整片行为。自己造词也可以，但必须明确定义；新造词无法调动已有先验，预训练词免费提供的含义，要用定义 token 补足。因此优先采用已有词。

它有两重锚定作用。在正文中锚定*执行*：每次出现，代理都调用相同行为；在平级参考中，则聚焦某类要寻找的事物。在指针中锚定*调用*：同一个词同时出现在提示词、文档和代码库时，代理更可靠地将这套共同语言与材料联系起来并访问它。

寻找用引导词重构文字的机会，例如三处都写出的三项特征，或指针用整句话表达一个概念。它们都适合压缩为一个词：

- “快速、确定、低开销” → *紧凑*，例如*紧凑*循环。
- “你信得过的循环” → *红灯*，把模糊关卡变成二元可观察状态：循环能针对缺陷*报红*，或不能。

收益有两个：更少 token，以及更清晰的思考挂钩。应假设每份文档里都存在可被引导词取代的复述，主动寻找。

**否定表达**是这一手段旁边的失败模式：通过禁止来引导，会把被禁止行为拉入上下文，使其*更*容易出现。说“不要想大象”，脑中就只有大象。否定是一个弱修饰语，会被强烈激活的概念覆盖，于是禁令半读起来像是在要求做那件事。用**肯定表达**说明目标行为，例如“写单行注释”，让被禁止行为根本不出现。只有无法正面表述的硬性护栏，才值得使用禁令；即便如此，也应配上正面的目标行为，让注意力落在该做什么上。

## 精简

- 将每个意思保存在**唯一权威来源**中，改变行为时只需改一处。**重复**是在多个位置表达相同意思，会增加维护和 token 成本，还让某个含义在阶梯上的显著性超过其真实地位。（它与引导词正好相反：引导词刻意重复的是词，而不是含义。）
- **环境**本身也是权威来源，例如 `package.json` 脚本、配置文件、目录布局、`--help` 输出。重述环境的文档就是**缓存**，是查询结果的副本，只有查询昂贵时才值得承担负担。缓存代理无法直接查到的内容：未写明的惯例、某项选择背后的原因、配置不会自述的陷阱。只需一个文件或一条命令的查询，留给环境，那里不会过时。
- 检查每一行的**相关性**：它是否仍与文档所做的事有关？一行内容可能从未与任务相关，例如纯粹讲解或本应外置的分支；也可能随所描述的行为或世界变化而过时。较短文档更容易保持相关。缺乏精简纪律时，默认结局是**沉积**：因为添加显得安全、删除显得冒险，陈旧层层累积，直到必须向下钻探才能找到仍有效的内容。
- 逐句寻找**无效指令**：模型默认就会遵守的指令，付出了负担却没传达新信息。判断标准是相对默认行为是否改变了模型表现，它取决于模型，而非读者。两人对某句话是否无效有分歧，实际是在争论默认行为；应通过运行文档判断，而不是辩论。某句不通过时，删除整句，不要只删几个字。这一标准也适用于引导词：弱到无法超越默认行为的词，例如面对本来就相当细致的代理说“要全面”，同样无效。修复方式是换更强的词，例如“持续追问到底”，而非更换技术。
